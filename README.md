# Analyse fonctionnelle ABC — Outil éducatif

Outil web destiné à soutenir l'observation et l'analyse fonctionnelle de situations éducatives selon la logique **A-B-C** :

- **A — Antécédent** : ce qui se passe juste avant le comportement ;
- **B — Comportement** : description concrète et observable ;
- **C — Conséquence** : ce qui se passe immédiatement après.

L'objectif est d'aider à observer plusieurs situations, rechercher des régularités et formuler des hypothèses prudentes afin d'adapter l'environnement et les réponses éducatives.

## Fonctionnalités

- gestion de plusieurs dossiers ;
- saisie structurée des observations ABC ;
- éléments de contexte, fréquence, durée et intensité ;
- hypothèses fonctionnelles ;
- filtres et synthèses ;
- sauvegarde locale dans le navigateur ;
- export / import JSON et export CSV ;
- impression / enregistrement PDF ;
- mode d'emploi intégré.

## Confidentialité

Les données saisies sont enregistrées **localement dans le navigateur**. Elles ne sont pas envoyées vers GitHub et ne sont pas stockées dans le dépôt.

Pour une démonstration publique ou un ordinateur partagé, privilégier des initiales ou un identifiant interne et éviter les informations nominatives inutiles.

**Ne pas déposer sur GitHub des exports contenant des données concernant des enfants.**

## Limites

Cet outil soutient l'analyse professionnelle. Il ne permet pas, à lui seul, d'établir avec certitude la fonction d'un comportement et ne remplace pas une évaluation clinique, médicale ou spécialisée lorsqu'elle est nécessaire.
